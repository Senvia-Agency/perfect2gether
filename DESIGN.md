## 1. Existing system
Source: src/index.css, src/components/ui, src/components/layout. Preserve current CRM style, sidebar and mobile navigation. No new brand or external fonts.
## 2. Tokens
Use semantic Tailwind background, foreground, card, primary, muted, muted-foreground, accent, border, destructive, ring. Existing primary 243 34% 45%, background 189 100% 98%, card white. Dark values inherit existing variables.
## 3. Typography

## 4. Spacing and layout
4px base: gaps/padding 2,3,4,6,8 Tailwind. Page p-4 md:p-6. Messages viewport height uses dvh minus current app header/footer. Desktop list 20rem and minmax(0,1fr) thread; mobile list or thread, back button. Each pane owns vertical scrolling; composer stays visible. Long words wrap.
## 5. Primitives
Existing Button, Input, Textarea, Dialog, DropdownMenu, AlertDialog, Avatar/initials. Conversation row, message bubble, attachment card, empty/error panel. Borders and shadow-sm follow existing cards. Focus rings, disabled/pending/error states mandatory.
## 6. Motion
Only existing short color transitions; spinner while work pending. Honor reduced motion. No decorative animation.
## 7. Accessibility
Label every icon control; keyboard send Enter and newline Shift+Enter; visible focus, dialogs have names/descriptions, polite upload status; do not steal typing focus on realtime events. Minimum 40px hit areas.
## 8. Privacy and debt
No message text in push payloads. Not end-to-end encrypted: membership protection at database/Storage level. Temporary file URLs expire quickly. Native notification permission remains user-driven. No claim of production delivery from local tests.
